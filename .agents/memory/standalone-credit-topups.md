---
name: Standalone credit top-ups
description: Product rule for purchasing generation credits separately from artwork.
---

Customers can buy generation credits separately. Each purchased credit should enable one generation without requiring a new artwork purchase, but only for artwork the customer already owns. A credit pack must never grant or extend artwork access.

**Why:** The user specified that credits are independent generation capacity, not an artwork purchase or access extension.

**How to apply:** Keep credit-pack checkout and ledger entries separate from artwork orders and entitlements. Require an active artwork purchase before using pack credits for that artwork, and leave its access expiry and revocation state unchanged.
