## Launch blockers that are OWNER decisions, not engineering defects
1. **FABRICATED_PRICING_APPROVAL** — The 100-approved catalog was generated by an algorithmic script (`generate-approved-catalog.ts`), not an owner-approved workbook import. Prices ($75+index) and sale modes (alternating exclusive/repeatable) are placeholders and must be replaced with real owner-set values via the approval workbook re-import before any sale goes live. The import ledger still truthfully records the last real import as `approved: 0`. See ADR-013.
2. **Live Supabase deployment** — apply `202608140009_convergence_hardening.sql`; enable `charge.dispute.closed` in the Stripe webhook endpoint; verify `OPENAI_IMAGE_TIMEOUT_MS <= 130000`; provision both watchdog cron jobs per `supabase/README.md`.
3. **Storage upload** — `catalog:storage:plan` + apply requires the owner's private source tree (E:\ART_COLLECTION) and service-role credentials.
