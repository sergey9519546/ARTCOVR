# SYSTEM MAP — ARTCOVR (Ground Truth)

## Stack
Next.js 16 (App Router, Turbopack), React 19, TypeScript 5, Tailwind CSS v4, tw-animate-css. Bun runtime. Supabase (PostgreSQL + RLS + Edge Functions + Storage + Auth). Stripe Checkout + webhooks. Playwright E2E. ESLint + `node --test`.

## Product Architecture
- **Catalog (DUAL SOURCE OF TRUTH)**: Display = build-time static `src/lib/artcovr/curated-public.json` (generated by `scripts/catalog/` projection; filtered by `selectPublicCatalog` → rightsApproved+published). Reservation/settlement = DB `artworks` (`catalog_id`, `is_listed`, approvals) via `reserve_artwork`. Static export (`output:"export"`) means catalog/price changes require redeploy. `verify-export-isolation.ts` runs post-build.
- **Commerce**: `purchases` (reservation → pending → paid → refunded). `stripe_events` for webhook tracking. Checkout idempotency via `idempotency_key`. SQL settlement locks artwork before purchase row.
- **Generation**: `generations` (queued/running/succeeded/blocked/failed/timed_out). Preview vs purchased phases. Rate limits. AI image pipeline.
- **Auth**: Supabase Auth (`auth.users`). `sign-in`, `my-images`, `bag`, `checkout` routes.
- **Themes**: `dark`, `light`, `red` (deprecated; light is authoritative fallback per `layout.tsx` bootstrap script).
- **Themes & Motion**: CSS variables, `prefers-reduced-motion`, coarse pointer bypass. WCAG AA required per AGENTS.md.

## Commerce Hardening (From AGENTS.md)
- Snapshot `base_object_key_snapshot`, `base_source_sha256_snapshot`, price at checkout.
- SQL settlement locks artwork before purchase row.
- Refund/revocation revokes clean high-res asset (`access_revoked_at`).
- Idempotency keys rotate only on terminal rejections.
